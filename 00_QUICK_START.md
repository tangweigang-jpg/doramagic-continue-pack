# Quick Start

## Outcome

load Continue as a source-controlled coding-agent workflow with policy checks, eval prompts, and recovery rules for unsafe or drifting code suggestions

## Two-Minute Path

1. Read `AGENTS.md`.
2. Copy the relevant host instruction into your AI coding host.
3. Run `06_EVALS/smoke_check.md`.
4. If the check fails, open `03_PITFALL_LOG.md`.
